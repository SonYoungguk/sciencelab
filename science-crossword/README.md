# 과학 용어 퍼즐 배틀

과학 교과서 용어로 만든 가로세로 퍼즐을 학생 최대 4명이 동시에 풀며 경쟁하는 실시간 게임입니다. 교사는 관전 화면으로 진행 상황을 봅니다.

## 게임 규칙

- 교사가 방을 만들면 4자리 방 번호가 생기고, 학생은 방 번호와 이름으로 참가합니다 (최대 4명).
- 교사가 시작하면 3초 뒤 모든 학생에게 같은 퍼즐이 열립니다. 퍼즐은 시작할 때마다 단어 목록에서 무작위로 골라 새로 배치합니다.
- 학생은 칸이나 문제를 누르고 단어 전체를 입력합니다. 다른 정답들로 모든 칸이 채워진 단어는 자동으로 맞힌 것으로 처리됩니다.
- 한 명이 퍼즐을 모두 맞히면 30초 카운트다운이 시작되고, 0초가 되면 게임이 끝납니다.
- 순위는 맞힌 단어 수로 정하고, 같으면 마지막 정답을 먼저 입력한 사람이 앞섭니다.

## 출제 범위

- 선생님 화면에서 **학년(중1·중2·중3·전체)**을 고른 뒤, 원하는 **단원을 여러 개 체크**해서 출제합니다.
- 기본 단원: 2015 개정 교육과정 중학교 과학 단원 이름을 기준으로 21개 단원, 240여 개 용어를 넣어 두었습니다. 교과서와 다를 수 있으니 필요하면 삭제하고 새로 올려 주세요.
- 한 판 단어 수: 10 / 15 / 20 / 고른 단원 전체
- "이번 판만 직접 입력하기"에 `용어 | 설명`을 적으면 저장 없이 그 목록으로 출제합니다.

## 단원 추가하기

1. 선생님 화면의 **양식 내려받기 (.xlsx)**를 누릅니다.
2. `용어` 시트에 학년·단원·용어·설명을 한 줄에 하나씩 채웁니다. (`작성 방법` 시트 참고)
3. **파일 올리기**로 올리면 읽은 결과(단원별 개수, 건너뛴 줄)를 보여 줍니다. **단원 목록에 저장**을 누르면 저장됩니다.
4. 같은 학년·단원·용어를 다시 올리면 설명이 새 내용으로 바뀝니다.
5. **저장된 단원 보기·삭제**에서 단원을 지울 수 있습니다. (삭제 버튼을 두 번 눌러야 지워집니다)

## 구성

- `index.html`: 게임 전체 (빌드 도구 없는 단일 HTML). Vercel에 정적 페이지로 배포합니다.
- `supabase/schema.sql`: Supabase 데이터베이스 구조.
- 실시간 데이터: Supabase (`science-crossword` 프로젝트, 서울 리전)
  - `rooms` 테이블: 방 번호(`code`)와 방 상태(`data` JSON: 상태, 퍼즐, 시작·종료 시각, 1등 정보)
  - `terms` 테이블: 학년, 단원, 용어, 설명 (선생님이 올린 용어 포함)
  - `players` 테이블: 방 번호, 학생 ID(`pid`), 학생 상태(`data` JSON: 이름, 자리, 맞힌 단어, 오답 수)
  - Realtime으로 변경 사항을 받고, 연결이 끊겨도 5초마다 다시 읽어 따라잡습니다.
  - 모든 기기는 Supabase 서버 시계에 맞춰 카운트다운을 계산합니다.
  - 3일 넘게 쓰지 않은 방은 새 방이 만들어질 때 자동으로 지워집니다.
- 로그인이 없는 교실용 게임이라, 방 번호를 아는 사람은 누구나 그 방의 데이터를 읽고 쓸 수 있습니다. 개인정보(실명 등)는 저장하지 않는 것을 권장합니다.

## 다른 Supabase 프로젝트로 옮길 때

1. Supabase SQL Editor에서 `supabase/schema.sql`을 실행합니다.
2. `index.html`의 `SUPABASE_URL`, `SUPABASE_KEY`(publishable key)를 새 프로젝트 값으로 바꿉니다.
